## 💡 Featured Projects

### 🩺 Family Care Circle – NLP-Powered Healthcare Communication
**Python | NLP | Hugging Face Transformers | Qwen2.5 | llama.cpp**

- Built a local NLP pipeline that transforms clinical notes into patient-friendly summaries, caregiver checklists, and child-friendly explanations.
- Implemented rule-based Named Entity Recognition (NER), persona-specific prompting, and medical fact-retention validation.
- Developed retry mechanisms, deterministic fallbacks, and evaluation workflows to improve information reliability.

### 👗 UNFOUND – AI-Powered Fashion Discovery Platform
**Python | FastAPI | React | CLIP | PostgreSQL | Supabase | pgvector**

- Developed an AI-powered fashion discovery platform featuring a catalogue of 1,300+ products from niche fashion brands.
- Implemented CLIP-based image embeddings and vector similarity search using PostgreSQL and pgvector.
- Integrated FastAPI backend services and React interfaces to support text-based and image-based product discovery.

### 🎙️ MeetSense – AI-Powered Meeting Intelligence
**Python | Whisper | pyannote.audio | T5-small | Qwen2.5 | Streamlit**

- Developed a meeting intelligence application that converts audio recordings into speaker-labelled transcripts, summaries, topics, decisions, and action items.
- Integrated Whisper for speech recognition, pyannote.audio for speaker diarisation, T5-small for summarisation, and Qwen2.5 for structured information extraction.
- Explored rolling-window audio processing, speaker embeddings, cosine similarity, and evaluation using WER, DER, and ROUGE.

### ☁️ CloudPilot – AWS Cloud Cost Monitoring & Optimisation
**Python | FastAPI | React | PostgreSQL | AWS | Docker**

- Built a full-stack cloud monitoring application integrating AWS Cost Explorer to retrieve and analyse cloud expenditure.
- Developed FastAPI endpoints, PostgreSQL integration, and a React dashboard for cost visualisation.
- Implemented optional CloudWatch-based EC2 monitoring and automated backend testing.

### 🛡️ SmartSafe – Intelligent Safety & Emergency Response Platform
**Python | Supabase | Location Intelligence | Edge-Fog-Cloud Architecture**

- Designed a three-tier Edge-Fog-Cloud safety framework for location-aware emergency response and incident management.
- Implemented location-based distance calculations using the Haversine algorithm.
- Integrated Supabase for backend data management and incident-related workflows.

### 🚘 Automatic License Plate Recognition System
**Python | YOLOv8 | OpenCV | SORT | EasyOCR | Supabase**

- Developed an automatic number plate recognition system using YOLOv8 for vehicle detection and SORT for object tracking.
- Integrated EasyOCR for extracting registration numbers from detected plates.
- Achieved 96% detection accuracy and approximately 32 FPS in project testing.
